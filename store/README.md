## Screenshot studio — quick start
The 4 slides form one **continuous panorama** (per-app art in `screenshots/art.js`,
authored in `tools/gen-store-scaffold/art/`) with the app mascot placed per slide.

**Phone** (required, 4 slides):
1. Raw app screens → `screenshots/raw/1.png` … `4.png` (or run `tools/gen-store-scaffold/capture-raws.mjs`).
2. `node tools/gen-store-scaffold/capture-slides.mjs petgo` → phone + both tablets, all locales.
3. Or manually: open `screenshots/index.html`, pick a language, **Full size**, capture each `.slide` at 1080×1920.

**Tablet** (7-inch 1200×1920 & 10-inch 1600×2560): captured by the same
`capture-slides.mjs` run; tablet raws live in `screenshots/raw-tablet/` (falls back
to the phone raws when absent). Preview: `screenshots/tablet.html`.

**Verify:** `node tools/gen-store-scaffold/verify-screenshots.mjs petgo` — exact
dimensions, panorama seam continuity, and contact sheets in `screenshots/out/`.

**Feature graphic:** `screenshots/feature-graphic.html` → capture `.feature` at **1024×500**.
