Kawicaksanan Privasi (Privacy Policy)

Pungkasan dianyari: 2026-10-04

Kawicaksanan Privasi iki njlentrehake kepriye kita ngatur informasi Panjenengan ing aplikasi PetGo (kasedhiya ing petgo.faishal.id).

1. Pangumpulan Informasi

Kita ngajeni privasi Panjenengan. Aplikasi PetGo dirancang minangka aplikasi offline-first lan privat. Kita ora nglumpukake, nyimpen ing server, nglacak, ngirim, utawa mbagi data pribadi Panjenengan menyang pihak sapa wae. Kabeh sing dilebokake tetep ana ing piranti Panjenengan.

2. Panyimpenan Data Lokal

Kabeh cathetan, checklist, lan setelan Panjenengan disimpen sacara lokal ing piranti (panyimpenan lokal browser utawa database lokal aplikasi). Data iki sakabehe ana ing kakuwasan Panjenengan lan bakal kabusak yen Panjenengan mbusak data aplikasi utawa cache panyimpenan lokal browser.

3. Layanan Pihak Katelu

Kanthi jujur kita aturake: ing njero aplikasi ora ana SDK analitik pihak katelu, ora ana iklan pelacak, lan ora ana pelacak apa wae. Nanging kaca web iki ngemot font saka Google Fonts lan gambar gendéra saka flagcdn.com; kekarone bisa nyathet alamat IP nalika kaca dimot — iki ing njaba kakuwasan kita. Kita ora masang piksel pelacakan utawa skrip analitik dhewe ing kaca iki.

4. Cookie

Kita ora masang cookie dhewe ing kaca iki lan ora nggunakake cookie kanggo analitik utawa pariwara. CDN pihak katelu ing ndhuwur bisa ngetrapake mekanisme teknise dhewe miturut kawicaksanane.

5. Dasar Hukum

Sajrone aturan pangreksan data (kalebu GDPR Pasal 6 lan UU Pelindungan Data Pribadi Indonesia) tumrap: amarga kita ora ngolah data pribadi ing server apa wae, ora ana pangolahan ing sisih kita sing mbutuhake dasar hukum. Saben pangolahan sing Panjenengan tindakake ing piranti Panjenengan dhewe adhedhasar idin lan kapentingan sah Panjenengan nggunakake aplikasi (GDPR Pasal 6 ayat 1 huruf a lan f). Pencathetan IP dening Google Fonts/flagcdn.com tundhuk marang kawicaksanane panyedhiya kasebut.

6. Retensi Data

Kita ora nyimpen data Panjenengan ing server, mula ora ana mangsa retensi ing sisih kita. Data lokal ing piranti Panjenengan kesimpen anggere Panjenengan nyimpen lan kabusak nalika Panjenengan mbusak.

7. Hak Panjenengan

Panjenengan bisa ngakses, mbenerake, lan mbusak data langsung ing piranti (cukup mbusak data aplikasi). Kanggo pitakon utawa panjalukan hak subjek data (akses, pambusakan, keberatan, portabilitas) miturut GDPR/UU PDP, hubungi kita ing support@faishal.id — kita bakal nanggapi ing wektu sing lumrah.

8. Pangowahan Kawicaksanan

Kita ora nglumpukake data bocah ing server apa wae amarga kabeh data mung kesimpen ing piranti Panjenengan. Yen Panjenengan yakin data bocah kakirim menyang kita kanthi ora sengaja, enggal hubungi support@faishal.id supaya kita bisa mbantu.

9. Hubungi Kita

Cathetan kesehatan (riwayat vaksin / informasi darurat) mung kesimpen ing piranti Panjenengan — ora tau dikirim menyang server kita. Aplikasi iki dudu piranti medis lan ora ngganteni saran tenaga kesehatan profesional.
