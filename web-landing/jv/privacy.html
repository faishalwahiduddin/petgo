Kawicaksanan Privasi - petgo

Dianyari pungkasan: 4 Oktober 2026

Kawicaksanan Privasi iki nerangake carane kami ngelola informasi Panjenengan ing aplikasi petgo (kasedhiya ing petgo.faishal.id) lan ing kaca web iki.

1. Pungutan Informasi

Aplikasi petgo dirancang minangka aplikasi offline-first sing njaga privasi. Kami ora nglumpukake, ora nyimpen ing server, ora nglacak, ora ngirim, utawa mbagekake data pribadi Panjenengan marang sapa wae. Ora ana akun, ora ana pendaftaran, lan ora ana pelacakan tindak-tanduk ing njero aplikasi.

2. Panyimpenan Data Lokal

Kabeh cathetan, kemajuan, lan setelan Panjenengan disimpen sacara lokal ing piranti Panjenengan (panyimpenan lokal browser utawa basis data lokal piranti). Data iki sakabehe ana ing kakuwasan Panjenengan lan bakal kabusak yen Panjenengan mbusak data aplikasi utawa ngresiki cache panyimpenan browser.

3. Layanan Pihak Katelu

Ing njero aplikasi: kami ora nganggo SDK analitik pihak katelu, ora nampilake iklan pelacak, lan ora nganggo layanan eksternal apa wae sing nyatheth aktivitas Panjenengan. Kaca web iki: dimuat saka server statis lan ngemot font saka Google Fonts sarta gambar gendhera saka flagcdn.com; layanan loro kasebut bisa nyatheth alamat IP Panjenengan ing log server standare nalika browser Panjenengan ngemot sumber daya kasebut. Saliyane iku kaca iki ora ngemot pelacak liyane.

4. Kuki / Cookie

Kaca web iki lan aplikasi petgo ora nemtokake kuki apa wae duweke dhewe lan ora nganggo pelacakan basis kuki. Wigatosaken bilih Google Fonts lan flagcdn.com bisa ngetrapake kawicaksanan panyimpenan dhewe nalika browser Panjenengan njaluk sumber daya saka pihak kasebut; iku ana ing sanjabane kakuwasan kami.

5. Dhasar Hukum (GDPR Pasal 6)

Dhasar hukume pangolahan miturut Pasal 6 GDPR yaiku (a) nindakake layanan sing Panjenengan suwun (nyawisake aplikasi) lan (b) kapentingan sah kami kanggo nyawisake aplikasi sing njaga privasi lan offline-first. Kami ora ngedol data pribadi Panjenengan — ora ana data sing kami kumpulake kanggo diedol.

6. Retensi Data

Amarga kabeh data mung kasimpen ing piranti Panjenengan, ora ana mangsa retensi ing pihak kami. Data Panjenengan kabusak nalika Panjenengan mbusak aplikasi, mbusak datane, utawa ngresiki cache panyimpenan browser.

7. Hak Subyek Data

Panjenengan nduweni hak akses, mbenerake, mbusak, portabilitas, lan nentang tumrap data pribadi Panjenengan miturut GDPR. Amarga kami ora nyimpen apa-apa ing server kami, ora ana data sisi-server sing bisa kami wenehake utawa busak; kanggo pitakon apa wae, hubungi support@faishal.id lan kami bakal mbantu.

8. Bocah / Anak-Anak

petgo dirancang kanggo kulawarga, kalebu bocah kanthi pandampingan wong tuwa utawa wali. Amarga aplikasi makarya offline sakabehe lan kami ora nglumpukake data apa-apa, ora ana data bocah sing diklumpukake, disimpen ing server, utawa dibagekake. Wong tuwa utawa wali nyekel kakuwasan pepak tumrap piranti lan data ing njerone.

9. Owah-owahan Kawicaksanan

Kami bisa ndianyari Kawicaksanan Privasi iki saka wektu kanggo wektu. Saben owah-owahan dipublikasikake ing kaca iki bebarengan karo tanggal versi paling anyar.

10. Hubungi Kami

Yen Panjenengan nduweni pitakon bab Kawicaksanan Privasi iki, mangga hubungi kami ing support@faishal.id.
