Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 14 Oktober 2026

Kebijakan Privasi ini menjelaskan bagaimana kami mengelola informasi Anda pada aplikasi PetGo (tersedia di petgo.faishal.id).

1. Pengumpulan Informasi / Data Collection

Kami sangat menghargai privasi Anda. Aplikasi PetGo didesain sepenuhnya sebagai aplikasi offline-first dan privat. Kami tidak mengumpulkan, menyimpan, melacak, mengirimkan, atau membagikan data pribadi Anda ke server pihak manapun.

2. Penyimpanan Data Lokal / Local Storage

Semua catatan progress, checklist, dan konfigurasi data Anda disimpan secara lokal pada perangkat Anda (menggunakan penyimpanan lokal browser atau database lokal handphone). Data ini sepenuhnya berada di bawah kendali Anda dan akan terhapus jika Anda membersihkan data aplikasi atau cache penyimpanan lokal browser Anda.

3. Aplikasi vs Situs Pemasaran / App vs Marketing Site

Aplikasi PetGo (Flutter / offline-first): kami tidak menggunakan SDK analitik pihak ketiga di dalam aplikasi, tidak menampilkan iklan komersial pelacak, dan data ibadah/catatan Anda tetap lokal di perangkat.

Situs pemasaran (petgo.faishal.id): halaman landing dapat memakai Google Analytics (GA4) dan/atau Meta Pixel secara opsional setelah Anda memberikan persetujuan melalui banner cookie. Data bersifat agregat (kunjungan, klik unduhan, interaksi blog); kami tidak mengirim PII dari formulir ke piksel. Anda dapat menolak persetujuan kapan saja; pilihan disimpan di penyimpanan lokal peramban.

Font pihak ketiga (mis. Google Fonts) dapat dimuat untuk penampilan situs. Lihat juga kebijakan penyedia layanan terkait.

4. Perubahan Kebijakan / Policy Updates

Kami dapat memperbarui Kebijakan Privasi ini sewaktu-waktu. Setiap perubahan akan dipublikasikan langsung pada halaman ini.

5. Hubungi Kami / Contact Us

Jika Anda memiliki pertanyaan tentang Kebijakan Privasi ini, silakan hubungi kami di support@faishal.id.
