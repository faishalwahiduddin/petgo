Kawijakan Privasi - petgo

Panungtungan diropéa: 4 Oktober 2026

Kawijakan Privasi ieu ngajelaskeun kumaha kami ngokolakeun informasi Anjeun dina aplikasi petgo (sadia di petgo.faishal.id) sareng dina kaca wéb ieu.

1. Pangumpulan Informasi

Aplikasi petgo dirancang salaku aplikasi offline-first anu ngajaga privasi. Kami henteu ngumpulkeun, henteu nyimpen di server, henteu ngalacak, henteu ngirim, atanapi ngabagikeun data pribadi Anjeun ka pihak mana waé. Henteu aya akun, henteu aya pendaptaran, sareng henteu aya pelacakan paripolah di jero aplikasi.

2. Panyimpenan Data Lokal

Sadaya catetan, kamajuan, sareng setelan Anjeun disimpen sacara lokal dina alat Anjeun (panyimpenan lokal browser atanapi basis data lokal alat). Data ieu sapinuhna aya dina kakawasaan Anjeun sareng bakal kahapus upami Anjeun ngahapus data aplikasi atanapi ngaberesihan cache panyimpenan browser.

3. Ladenan Pihak Katilu

Di jero aplikasi: kami henteu nganggo SDK analitik pihak katilu, henteu nampilkeun iklan pelacak, sareng henteu nganggo ladenan éksternal naon waé anu ngarékam kagiatan Anjeun. Kaca wéb ieu: dimuat ti server statis sareng ngamuat font ti Google Fonts sareng gambar bandéra ti flagcdn.com; kadua ladenan éta tiasa nyatet alamat IP Anjeun dina log server standarna nalika browser Anjeun ngamuat sumber daya éta. Salian ti éta kaca ieu henteu ngamuat pelacak sanés.

4. Kuki / Cookie

Kaca wéb ieu sareng aplikasi petgo henteu netepkeun kuki naon waé milik kami sareng henteu nganggo pelacakan basis kuki. Punten perhatoskeun yén Google Fonts sareng flagcdn.com tiasa nerapkeun kawijakan panyimpenan nyalira nalika browser Anjeun nyuhunkeun sumber daya ti pihak éta; éta aya di luar kakawasaan kami.

5. Dasar Hukum (GDPR Pasal 6)

Dasar hukum pamrosésan numutkeun Pasal 6 GDPR nyaéta (a) ngalaksanakeun ladenan anu Anjeun pintakeun (nyayogikeun aplikasi) sareng (b) kapentingan sah kami pikeun nyayogikeun aplikasi anu ngajaga privasi sareng offline-first. Kami henteu ngajual data pribadi Anjeun — henteu aya data anu kami kumpulkeun pikeun dijual.

6. Retensi Data

Kusabab sadaya data ngan ukur disimpen dina alat Anjeun, henteu aya mangsa retensi di pihak kami. Data Anjeun kahapus nalika Anjeun ngahapus aplikasi, ngahapus datana, atanapi ngaberesihan cache panyimpenan browser.

7. Hak Subjék Data

Anjeun gaduh hak aksés, ngalereskeun, ngahapus, portabilitas, sareng nentang kana data pribadi Anjeun numutkeun GDPR. Kusabab kami henteu nyimpen naon-naon di server kami, henteu aya data sisi-server anu tiasa kami pasihkeun atanapi hapus; kanggo patarosan naon waé, hubungi support@faishal.id sareng kami bade ngabantos.

8. Barudak

petgo dirancang kanggo kulawarga, kalebet barudak kalayan pangaping kolot atanapi wali. Kusabab aplikasi jalanna offline sapinuhna sareng kami henteu ngumpulkeun data naon-naon, henteu aya data barudak anu dikumpulkeun, disimpen di server, atanapi dibagikeun. Kolot atanapi wali nyepeng kakawasaan pinuh kana alat sareng data di jerona.

9. Parobahan Kawijakan

Kami tiasa ngamutahirkeun Kawijakan Privasi ieu ti waktos ka waktos. Unggal parobahan dipedalkeun dina kaca ieu sareng tanggal vérsi pangénggalna.

10. Hubungi Kami

Upami Anjeun gaduh patarosan ngeunaan Kawijakan Privasi ieu, mangga hubungi kami di support@faishal.id.
