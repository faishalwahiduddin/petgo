Kawijakan Privasi (Privacy Policy)

Panungtungan diropéa: 2026-10-04

Kawijakan Privasi ieu ngajelaskeun kumaha kami ngatur informasi Anjeun dina aplikasi PetGo (sayogi di petgo.faishal.id).

1. Pangumpulan Informasi

Kami ngajénan privasi Anjeun. Aplikasi PetGo dirancang salaku aplikasi offline-first anu privat. Kami henteu ngumpulkeun, nyimpen di server, ngalacak, ngirim, atanapi ngabagikeun data pribadi Anjeun ka pihak mana waé. Sadaya anu diasupkeun tetep aya dina alat Anjeun.

2. Panyimpenan Data Lokal

Sadayana catetan, checklist, jeung setélan Anjeun disimpen sacara lokal dina alat (panyimpenan lokal browser atanapi database lokal aplikasi). Data ieu sapinuhna aya dina kakawasaan Anjeun sarta bakal kapupus upami Anjeun mupus data aplikasi atanapi cache panyimpenan lokal browser.

3. Layanan Pihak Katilu

Sacara jujur kami nepikeun: di jero aplikasi teu aya SDK analitik pihak katilu, teu aya iklan palacak, sareng teu aya palacak naon waé. Nanging kaca wéb ieu ngamuat font ti Google Fonts sareng gambar bandéra ti flagcdn.com; kaduana tiasa nyatet alamat IP Anjeun nalika kaca dimuat — ieu di luar kakawasaan kami. Kami henteu masang piksel palacak atanapi skrip analitik nyalira dina kaca ieu.

4. Cookie

Kami henteu nempatkeun cookie nyalira dina kaca ieu sareng henteu nganggo cookie kanggo analitik atanapi pariwara. CDN pihak katilu di luhur tiasa nerapkeun mékanisme téknisna nyalira saluyu kawijakanana.

5. Dasar Hukum

Sapapanjang aturan panyalindungan data (kalebet GDPR Pasal 6 sareng UU Pelindungan Data Pribadi Indonesia) lumaku: kusabab kami henteu ngolah data pribadi dina server mana waé, teu aya pamrosésan di sisi kami anu meryogikeun dasar hukum. Sakumna pamrosésan anu Anjeun lakukeun dina alat Anjeun nyalira lumangsung atas dasar idin sareng kapentingan sah Anjeun ngagunakeun aplikasi (GDPR Pasal 6 ayat 1 hurup a sareng f). Pencatetan IP ku Google Fonts/flagcdn.com tunduk kana kawijakan panyadia éta.

6. Retensi Data

Kami henteu nyimpen data Anjeun dina server, janten teu aya mangsa reténsi di sisi kami. Data lokal dina alat Anjeun kasimpen salami Anjeun nyimpenna sareng kapupus nalika Anjeun ngahapus.

7. Hak Anjeun

Anjeun tiasa ngaksés, ngalereskeun, sareng ngahapus data langsung dina alat (cukup pupus data aplikasi). Kanggo patarosan atanapi pamundut hak subjék data (aksés, pupus, bantahan, portabilitas) numutkeun GDPR/UU PDP, hubungi kami di support@faishal.id — kami baris ngawaler dina waktos anu lumrah.

8. Parobahan Kawijakan

Kami henteu ngumpulkeun data barudak dina server mana waé kusabab sadaya data ngan kasimpen dina alat Anjeun. Upami Anjeun yakin data barudak kakirim ka kami teu ngahaja, geura hubungi support@faishal.id supados kami tiasa ngabantu.

9. Hubungi Kami

Catetan kaséhatan (riwayat vaksin / informasi darurat) ngan kasimpen dina alat Anjeun — moal pernah dikirim ka server kami. Aplikasi ieu sanés alat médis sareng henteu ngagentos naséhat tanaga kaséhatan profésional.
